# Просмотр DXF и PDF

Офлайн-приложение (PWA) для быстрого просмотра DXF-развёрток и PDF-чертежей: сетка миниатюр, просмотр с масштабом, переход чертёж ⇄ развёртка по обозначению.

Открыть: https://mrtekhnik.github.io/dxf-viewer/

PDF отображается библиотекой [pdf.js](https://github.com/mozilla/pdf.js) (Apache 2.0), файлы в папке `lib/`.
